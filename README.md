# World Cup Clustering Analysis

University assignment (Artificial Intelligence, University of Europe for Applied 
Sciences) applying K-Means and hierarchical clustering to a World Cup preference 
dataset.

## Tools
- Python
- pandas
- scikit-learn

## What it covers
- Cleaning the dataset and handling missing values
- Standardizing and normalizing feature values
- Using the Elbow Method to identify a suitable number of clusters (K)
- Performing K-means clustering
- Performing hierarchical clustering and creating a dendrogram
- Comparing K-means and hierarchical clustering results and interpreting the clusters
